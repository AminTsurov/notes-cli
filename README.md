# Notes CLI

Консольное приложение для управления заметками, написанное на Java.

## Возможности

*   **Подсчет заметок:** Используйте команду `count`, чтобы быстро узнать количество сохраненных заметок.
*   **Поддержка Docker:** Приложение упаковано в контейнер и может быть легко запущено с помощью Docker.
*   **CI/CD пайплайн:** Автоматизированный процесс сборки и тестирования проекта (см. `.github/workflows`).

## Установка и запуск

### Способ 1: Сборка из исходного кода (Java)
1.  Убедитесь, что у вас установлена **Java**.
2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/AminTsurov/notes-cli.git
    ```
3.  Перейдите в директорию проекта:
    ```bash
    cd notes-cli
    ```
4.  Скомпилируйте и запустите приложение. Точная команда зависит от структуры проекта (точка входа указывается в `src/com/example/`).

### Способ 2: Запуск через Docker
1.  Убедитесь, что у вас установлен **Docker**.
2.  Соберите образ из `Dockerfile`:
    ```bash
    docker build -t notes-cli .
    ```
3.  Запустите контейнер:
    ```bash
    docker run notes-cli
    ```

## Использование

После запуска приложения вы можете использовать команду `count`, чтобы узнать количество заметок.

**Пример команды:**
```
count
```
